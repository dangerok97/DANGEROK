# Action Engine — Product

Last updated: 2026-08-05

## One line

ORA turns a Home priority into a short guided conversation (one question per screen) that produces real calendar sessions, reminders, projects, and Brain updates — never an empty “Apri” page.

## User promise

- **Apri / Organizza / Inizia / card press** always starts a collaborative flow.
- One question at a time; prefer quick-reply chips.
- Not infinite chat. Not a chatbot.
- Medical flows are logistics only — never advice or diagnoses.
- After completion, Home evolves (e.g. study exam → “Sessione 1 oggi 18”).

## Flows

| Flow | When | Outcome |
|------|------|---------|
| Study | Exam / education | Plan, calendar sessions, flashcard/quiz hooks, reminders |
| Event | Concert / appointment | Calendar, Maps, leave-time reminder |
| Travel | Trip | Destination/transport intake → calendar, luggage, docs; weather blocked if no creds |
| Medical | Visit | Calendar, Maps, doc checklist, reminder — no clinical content |
| Admin | Bill / payment / paperwork | Reminder, calendar deadline, document link |
| Generic | Anything else | Still helps (organize / remind / calendar) |

## Entry points

- Home V2 primary focus actions and card
- Priority list cards
- Resume of an in-progress Action Engine session
- Shared API for future Documents / Decisions reuse
