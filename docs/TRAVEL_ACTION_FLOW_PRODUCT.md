# Travel Action Flow — Product

Last updated: 2026-08-05

## What the user experiences

1. Says something like «Andrò in vacanza dal 9 al 24 agosto» or «Vacanza Vibo Marina».  
2. ORA classifies **travel / vacation**, extracts period/destination when possible.  
3. Asks **only what is missing** (chips first, text allowed) — destination, departure place, transport, bookings, companions, calendar sync, optional prep.  
4. Shows a **preview** of the Travel Project (period, maps estimate, proposed calendar events).  
5. On **confirm**, creates the living project; Google Calendar events only if the user opted in **and** confirmed.  
6. Home evolves: vacation → days until → departure day → during → welcome back.  

## Not this

- Not a packing checklist app as the primary UX  
- Not a calendar or task manager  
- No invented weather, traffic, or medical advice  

## Project contents

Period, destination, departure, participants, transport, bookings, proposed calendar events, Maps deep link + honest distance/time, optional prep, document links, future slots for photos/expenses/email.
